# Papaya Projesi — opencode Bilgileri

Bu proje bir Vite + React + TypeScript uygulamasıdır.

## Önemli dosyalar

- `opencode.json` — opencode yapılandırması
- `.opencode/agent/md-writer.md` — .md dosyaları için agent
- `README.md` — proje ana dökümantasyonu
- Tüm `.md` dosyaları dökümantasyon amaçlıdır

## Komutlar

- `npm run dev` — geliştirme sunucusu
- `npx tsc --noEmit` — tip kontrolü
- `npx vite build` — production build

## Not

.md dosyalarında yapılan her değişiklik README ve diğer dökümantasyon dosyalarına da yansıtılmalıdır.
